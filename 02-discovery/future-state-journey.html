Future-state journey: an affordable instalment plan the customer can keep

A customer with one or two open claims and irregular shift income sets up a repayment plan that fits what she can actually pay, without risking a missed payment.

  1. 1

    See my case

    User action
    Opens reminder link, sees both claims together → knows total owed instantly.

    Internal state
    Case data verified and freshness-checked → context captured from first click.

    Pain point addressed
    Unclear scope and confusion → customer stays instead of closing.

  2. 2

    Share income simply

    User action
    Picks "typical month" or "this month" range → answers without guessing.

    Internal state
    Uncertain inputs flagged low-confidence → routed to a human, never auto-declined.

    Pain point addressed
    Ambiguous income question → stated purpose reduces abandonment.

  3. 3

    Choose a plan that fits

    User action
    Compares plans with a safe-amount default → picks sustainable, not shortest.

    Internal state
    Options bounded by affordability, not highest payment → fairer, lower default risk.

    Pain point addressed
    Fewest months looks "right" → prevents missed second payment.

  4. 4

    Confirm and stay on track

    User action
    Confirms plan, sees missed-payment rules → trusts the commitment.

    Internal state
    Plan, reasoning and override trail logged → agents skip repeat checks.

    Pain point addressed
    Fear of consequences and missed payments → early help path.

Competitive advantages over the manual workaround

What the digital journey does that a phone call and repeated agent checks cannot.

  1. Fewer drop-offsPlain-language income prompts and a "safe amount" default replace call-back guesswork, so the customer finishes the journey the first time.
  2. No repeated checks for agentsEntered data, confidence flags and reasons arrive with the case, so agents correct exceptions instead of re-asking everything.
  3. Plans built to be keptAffordability-bounded options reduce missed payments, so a rising SSR reflects better outcomes rather than plans that collapse.
Strategy: make it easy for consumers to agree to an affordable, sustainable instalment plan.
